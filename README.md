# HỆ THỐNG TRẮC NGHIỆM - BẢN GIAO DIỆN HOÀN THIỆN

## Cách cập nhật GitHub
Upload/ghi đè các file trong gói này vào thư mục gốc repository `on-tap-cac-mon-hoc`.

**Quan trọng:** Giữ nguyên file `config.js` hiện tại của bạn nếu file đó đã chứa Supabase URL và Publishable Key. Gói giao diện này không chứa `config.js` để tránh ghi đè khóa đang dùng.

Các file chính:
- `index.html`: Trang chủ.
- `quiz.html`: Trang làm bài.
- `admin.html`: Trang quản trị.
- `styles.css`: Toàn bộ giao diện.
- `app.js`: Logic làm bài.
- `admin.js`: Logic quản trị.
- `chapter4.json`: Dữ liệu Chương 4.
- Các file `.svg`: hình minh họa và meme kết quả.

Sau khi push GitHub, chờ GitHub Pages cập nhật rồi nhấn Ctrl+F5.
